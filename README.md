# Calculadora Basic Android

Uma simples calculadora desenvolvida com tecnologias web para plataforma Android.

## 📱 Sobre o Projeto

Este projeto é uma aplicação de calculadora básica construída com HTML, CSS e JavaScript, oferecendo uma interface limpa e intuitiva para realizar operações matemáticas simples. É um excelente projeto educacional para aprender JavaScript!

## 🛠️ Tecnologias Utilizadas

- **JavaScript** (64.7%) - Lógica da aplicação e funcionalidades
- **CSS** (25.5%) - Estilização e layout responsivo
- **HTML** (9.8%) - Estrutura da página
- **Cordova-Android 12** - Framework para build de aplicação Android

## ✨ Funcionalidades

- ✅ Operações básicas (soma, subtração, multiplicação, divisão)
- ✅ Interface responsiva e amigável para mobile
- ✅ Cálculos em tempo real
- ✅ Limpeza de dados (reset)
- ✅ Compatível com Android

## 📖 Como Usar

1. Abra a aplicação no seu dispositivo Android ou emulador
2. Clique nos números para inserir valores
3. Selecione a operação desejada (+, -, ×, ÷)
4. Clique em = para ver o resultado
5. Use o botão C para limpar a calculadora

## 🚀 Começando

### Pré-requisitos

- Node.js e npm instalados
- Android SDK ou emulador Android
- Cordova CLI instalado

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/AleDev10/Colculadora_Basic_Android.git
cd Colculadora_Basic_Android
```

2. Instale as dependências:
```bash
npm install
```

3. Adicione a plataforma Android:
```bash
cordova platform add android
```

4. Execute a aplicação:
```bash
cordova run android
```
